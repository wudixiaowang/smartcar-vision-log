# fospeed 视觉练手记录

我在备战全国大学生智能汽车竞赛（佛山大学 **fospeed** 车队，22 届 · 2027 赛季）视觉方向时，
一步一步动手的记录。

这个仓库不是教程，是我真实跑过的每一小步：**图 → 一串数字 → 切一块看 → 调阈值 → 自己拍图采数据 → 标注 → 把标注读回来**。
下面出现的每个数字，都是我自己电脑上跑出来的输出。

## 为什么练这条线，而不是直接上 YOLO

招新指南里视觉方向入组考核的原话是「**用真车采图调一组识别阈值 + 参与真实数据集采集标注**」，
AI 那部分写在「有余力」一档。所以我练的顺序是：先传统图像处理（曝光 / 白平衡 / 阈值 / ROI），
再采集与标注，训练等能用实验室机器的时候再说。

本机条件决定了这个顺序，也决定了哪些步骤我根本不在本机做：

    显卡   AMD RX 6500 XT 4GB（没有 CUDA）→ 本地不训练模型
    网络   4G → 练手工具必须零下载
    所以   本机只跑 CPU 能跑的、不装大东西的活

## 目录

    vision/see_image.py          把一张图读成一排排数字：shape / 某个像素 / 切片 / 阈值白占比
    vision/see_roi.py            切一块 ROI 出来算：整图 vs ROI 的白占比对比
    vision/阈值实验.py            同一张图按 60/100/140/180 四个阈值切，输出对比图
    vision/标注工具.py            自己写的图片标注小工具（OpenCV + Pillow，没用现成标注框架）
    vision/打开标注工具.cmd        双击启动标注工具
    vision/运行阈值实验.cmd        双击跑阈值实验
    vision/run_see_roi.cmd       双击跑 ROI 那一支
    vision/run_see_image.cmd     双击跑「读成数字」那一支
    vision/dataset/images/       我自己拍的照片
    vision/dataset/labels/       YOLO 格式标注（一个物体一行）+ classes.txt
    vision/样例照片/              脚本合成的顺光 / 逆光 / 夜晚三张样例图（**不是真照片**）

## 怎么跑

Windows 上双击对应的 `.cmd` 就行，需要 `python` 在 PATH 里。依赖只有三个：

    pip install opencv-python pillow numpy

（仓库里的 `.cmd` 已经改成从 PATH 找 python；我本机是用户级 Python 3.14 + opencv-python 5.0.0 + Pillow 12.3.0 + numpy 2.5.3。）

自己写标注工具的原因：常用标注框架在本机（Python 3.14 + 4G 网络 + 无 CUDA）装得上但用不了，
索性用已装好的 OpenCV + Pillow 写一个：读图用 Pillow（顺手解决中文路径和手机竖拍的 EXIF 转正），
画界面用 OpenCV，状态条用 Pillow 的字体渲染（OpenCV 画不出中文）。键位：数字键 1/2/3 切类别，
鼠标拖框，D 下一张 / A 上一张 / U 撤销 / C 清空 / Q 退出。

## 别人想从零上手：六步

这个仓库是我的练手记录，不是教程。但如果你也是零基础、想走一遍同样的路，照这个顺序做就行 ——
每一步都能双击跑起来，都能在屏幕上看到真实数字。

    第 0 步  装 Python（安装时记得勾 Add to PATH），再装三个库：
             pip install opencv-python pillow numpy -i https://pypi.tuna.tsinghua.edu.cn/simple
    第 1 步  把仓库下下来（绿色 Code 按钮 → Download ZIP，或者 git clone），放哪都行
    第 2 步  双击 vision/run_see_image.cmd
             屏幕上会打印：一张图的行数 / 列数、某个像素装着的三个数、切片的结果、阈值切出来的白占比。
             先接受这一件事 —— 图在电脑里就是一排排数字
    第 3 步  双击 vision/run_see_roi.cmd
             只算画面里的一块（ROI）会少算很多格子，同一个阈值下白占比从 73.19% 变成 88.26%
             → 结论：阈值和范围都不能写死在代码里
    第 4 步  双击 vision/运行阈值实验.cmd
             同一张图按 60 / 100 / 140 / 180 四个阈值切开，看生成的那张对比图，自己回答：线该画在哪？
    第 5 步  拿手机拍你自己的东西（顺光一张、逆光一张、关灯开台灯一张），照片丢进 vision/dataset/images/
             竖拍不用管，读图的脚本会按 EXIF 转正
    第 6 步  双击 vision/打开标注工具.cmd 框物体：数字键 1/2/3 选类别，鼠标拖框，D 翻下一张
             框完 vision/dataset/labels/ 里会出现同名 .txt —— 那个文件就是「标准答案」

**训练那一步别在本机折腾**：如果机器上没有 NVIDIA 显卡（我的是 AMD RX 6500 XT 4GB，跑不了 CUDA），
本地装 PyTorch 训练只是浪费时间，等能用实验室机器或云显卡时再说。
先把「采图 → 调阈值 → 标注」这半边做熟 —— 入组考核真正考的就是这半边。

## 数据集

`vision/dataset/` 是我自己拍的公仔照片（手机竖拍，**文件里带 EXIF 方向标记** —— 读图时要用 `ImageOps.exif_transpose` 转正，否则框的坐标会整片错位）
加上用自己写的工具框出来的答案。标注是 YOLO 的 txt 格式，每行一个物体：

    <类别> <中心x> <中心y> <宽> <高>      全部是 0~1 的小数（除以图宽图高），换分辨率不失效

类别表 `classes.txt` 只有三个 ASCII 名：`block` 色块 / `cone` 锥桶 / `doll` 公仔（车队吉祥物小老虎）。
